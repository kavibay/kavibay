Download the installer All releases

This build is unsigned

No free code-signing option exists that Windows trusts, so the first launch hits SmartScreen: “Windows protected your PC” → More info → Run anyway. Nothing about that dialog is specific to this app — every unsigned installer gets it.

If you want certainty about what you downloaded, every release ships a SHA256SUMS.txt; compare it before you run the file. Or skip the binary and build from source.

There is no macOS build yet. The code paths exist, but nothing has ever been compiled on a Mac, and the transparent window leans on Apple private APIs — so this needs real work, not a checkbox.

One message when there is a macOS build worth trying. No list, no newsletter.

AppImage and .deb, built by the same release workflow as the Windows artifacts.

Download for Linux Run on Linux

X11 only, in practice

On Wayland, pinned widgets do not stay on top — Wayland grants no client that right, so this is not a bug that can be fixed here. On X11 everything works. The same unsigned-binary caveat as Windows applies.

Build it on your own machine.

The repo is the whole product. Three commands and you are running your own copy.

  1. 01

    Install the toolchain

    Node 20+ and Rust stable via rustup. On Windows also the Visual Studio Build Tools with Desktop development with C++. WebView2 is already on Windows 11; older versions need the Evergreen runtime. After installing rustup, open a new terminal — otherwise the build cannot find cargo.

  2. 02

    Get the source

    git clone https://github.com/aswetlow/kavibay.git
cd kavibay
npm install
  3. 03

    Run it

    npm run tauri dev

    The first start compiles the Rust backend and takes a few minutes; after that the Vue side hot-reloads. Nothing appears on screen — that is the design. Press Ctrl + Space or double-click the tray icon.

  4. 04

    Make yourself a binary

    npm run package:win              # NSIS installer
npm run package:win:standalone   # single .exe, no installer
npm run package:linux            # AppImage + .deb

    Everything lands in src-tauri/target/release/. Built this way it is your binary — no SmartScreen question about who signed it.

Linux system libraries, the X11 / Wayland comparison and what to do when it does not start: docs/getting-started.md .
