# Desks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add named desks with per-desk widget placements and palette chrome, shared widget content across desks, and a compact desk switcher in the command-palette footer.

**Architecture:** Persist `kavibay:layout-v4` as a global widget catalog + per-desk placements. `WidgetHost` owns the v4 document, derives a live `WidgetInstance[]` for the active desk (join catalog + placements), and keeps existing inject APIs. Pure helpers in `deskLogic.ts` / `layoutLogic.ts` own migrate/add/rename/delete/also-on/remove rules.

**Tech Stack:** Vue 3 + TypeScript, Vite, Tauri 2 overlay, localStorage (no new deps). Node assert scripts + `npx vue-tsc --noEmit`.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-22-desks-design.md`
- Terminology: **desk** (not workspace) in UI copy and comments
- Storage: `kavibay:layout-v4`; migrate once from `kavibay:layout-v3` (keep v3 unread as fallback)
- Shared content: `kavibay:<widget>:<instanceId>` unchanged
- Geometry / hidden / sticky = per `DeskPlacement`; title / hideTitle = catalog
- Create / duplicate → active desk only; share via explicit **Also on this desk**
- Remove on 2+ desks → prompt This desk only | All desks
- Delete desk → confirm; dispose exclusive catalog entries; cannot delete last desk
- Palette chrome is per desk; cockpit open/focus remain session-level
- No Vitest — assert scripts + vue-tsc + manual UI
- Commit after each task (use `C:\Program Files\Git\bin\git.exe` if `git commit` fails on `--trailer`)

### Task 1: Types + pure desk/layout helpers + migrate

**Files:**
- Modify: `src/core/host/types.ts`
- Create: `src/core/host/deskLogic.ts`
- Create: `src/core/host/deskLogic.assert.ts`
- Modify: `src/core/host/layoutLogic.ts`

**Interfaces:**
- Consumes: existing `WidgetInstance`, `SavedLayoutV3`, `normalizeInstance`, `newInstanceId`
- Produces:
  - Types: `DeskPlacement`, `Desk`, `WidgetCatalogEntry`, `SavedLayoutV4`
  - `LAYOUT_STORAGE_KEY_V4 = "kavibay:layout-v4"`
  - `migrateV3ToV4(v3: SavedLayoutV3): SavedLayoutV4` — one desk `"1"`, catalog+placements from instances, palette on that desk
  - `activeDesk(layout: SavedLayoutV4): Desk`
  - `instancesForDesk(layout: SavedLayoutV4, deskId: string): WidgetInstance[]` — join catalog∩placements
  - `addDesk(layout): { layout; deskId }` — next default name `"2"`, `"3"`, …
  - `renameDesk(layout, deskId, name): SavedLayoutV4`
  - `deleteDesk(layout, deskId): { layout; disposedInstanceIds: string[] }` — throws/returns null if last desk; drops exclusive catalog entries
  - `setActiveDesk(layout, deskId): SavedLayoutV4`
  - `addCatalogInstance(layout, entry, placement): SavedLayoutV4` — create on active desk
  - `placeOnDesk(layout, instanceId, deskId, offset): SavedLayoutV4 | null` — also-on; null if missing/already placed
  - `removeFromDesk(layout, instanceId, deskId): { layout; disposed: boolean }` — placement only; dispose catalog if no placements left
  - `removeEverywhere(layout, instanceId): SavedLayoutV4` — strip all placements + catalog entry
  - `desksWithInstance(layout, instanceId): string[]`
  - `catalogNotOnDesk(layout, deskId): WidgetCatalogEntry[]`
  - `loadLayout(registry): SavedLayoutV4` — try v4, else migrate v3/v2/defaults and `saveLayout`
  - `saveLayout(layout: SavedLayoutV4): void`

- [ ] **Step 1: Add v4 types to `types.ts`**

Add (keep existing `WidgetInstance` / `SavedLayoutV3`):

```ts
export interface DeskPlacement {
  instanceId: string;
  offset: WidgetPosition;
  width?: number;
  height?: number;
  contentScale?: number;
  hidden?: boolean;
  sticky?: boolean;
}

export interface Desk {
  id: string;
  name: string;
  palette: WidgetPosition;
  paletteSticky?: boolean;
  paletteWidth?: number;
  paletteListHeight?: number;
  placements: DeskPlacement[];
}

export interface WidgetCatalogEntry {
  instanceId: string;
  typeId: string;
  title?: string;
  hideTitle?: boolean;
}

export interface SavedLayoutV4 {
  activeDeskId: string;
  desks: Desk[];
  catalog: WidgetCatalogEntry[];
}
```

- [ ] **Step 2: Implement `deskLogic.ts` with the functions listed above**

Rules to encode exactly:
- `migrateV3ToV4`: desk id+name `"1"`; each instance → catalog fields + placement geometry; `activeDeskId` = that desk
- `deleteDesk`: refuse when `desks.length === 1`; collect `instanceId`s whose only placement was on deleted desk → remove from catalog and return as `disposedInstanceIds`
- `placeOnDesk`: no-op/null if catalog missing or placement already exists on target desk
- `removeFromDesk`: if last placement, remove catalog entry and `disposed: true`

Comment each exported function with a one-line purpose.

- [ ] **Step 3: Wire `layoutLogic.ts` load/save to v4**

- Export `LAYOUT_STORAGE_KEY_V4`
- `loadLayout` returns `SavedLayoutV4`
- Prefer v4 JSON; else load/parse v3 (existing path) → `migrateV3ToV4` → `saveLayout(v4)` → return
- Keep v2→v3 path, then migrate that result to v4
- `saveLayout` writes normalized v4 only to `LAYOUT_STORAGE_KEY_V4`
- Keep `createInstance` / `duplicateInstance` returning `WidgetInstance` for host to split into catalog+placement (or add thin wrappers in `deskLogic` that the host prefers)

- [ ] **Step 4: Assert script `deskLogic.assert.ts`**

Cover at least:
1. migrate v3 with 2 instances → 1 desk, 2 catalog, 2 placements
2. addDesk → names `"1"` then `"2"`; active unchanged until `setActiveDesk`
3. placeOnDesk same instance on desk 2 → `desksWithInstance` length 2
4. removeFromDesk one desk → catalog remains; remove last → disposed
5. deleteDesk with exclusive instance → id in `disposedInstanceIds`; shared instance survives
6. delete last desk → rejected

Run: `npx tsx src/core/host/deskLogic.assert.ts` (or `npx vite-node` if needed)  
Expected: prints `ok` / exit 0

- [ ] **Step 5: Commit**

```bash
git add src/core/host/types.ts src/core/host/deskLogic.ts src/core/host/deskLogic.assert.ts src/core/host/layoutLogic.ts
git commit -m "feat(desks): layout-v4 types, migrate, and deskLogic helpers"
```

- [ ] **Step 1: Load v4 into host state**

Replace flat `layout = loadLayout(...)` usage with:
- `layoutDoc` reactive/`ref<SavedLayoutV4>`
- `palette*` and `instances` derived from `activeDesk(layoutDoc)` via `instancesForDesk`
- Prefer keeping a writable derived `instances` array that writes back into the active desk’s placements + catalog on mutate (mirror today’s in-place mutations), **or** replace each mutator to patch `layoutDoc` then rebuild — pick one approach and stick to it (recommend: patch `layoutDoc`, reassign active placement fields; expose `computed` instances for reads and find-by-id helpers for writes)

- [ ] **Step 2: Adapt mutators**

| Today | Desk-aware behavior |
|-------|---------------------|
| add widget | catalog + placement on active desk; `onCreate` |
| duplicate | new catalog + placement on active desk; `onDuplicate` |
| move/resize/sticky/hidden | update **placement** on active desk only |
| title / hideTitle | update **catalog** entry |
| remove | if `desksWithInstance.length > 1`, do not hard-delete here — Task 3 UI prompts; host exposes `removeFromDesk` / `removeEverywhere` |
| persist `watch` | `saveLayout(layoutDoc)` |

On `removeEverywhere` / delete-desk disposed ids: call `onDispose` once per disposed `instanceId`.

- [ ] **Step 3: Implement switch desk**

`kavibaySwitchDesk(deskId)`:
1. Ensure current palette + placements already reflected in `layoutDoc` (flush any local refs)
2. `layoutDoc = setActiveDesk(layoutDoc, deskId)`
3. Rebind palette refs from new active desk
4. Clear session focus/preview ids if they are not on the new desk
5. `saveLayout`
