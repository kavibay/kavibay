# Clipboard

Browse and reuse recent clipboard entries. On Windows, newly captured entries
show the foreground application's icon when the process can be resolved. This
is source metadata, not image-content recognition, so screenshot tools may be
identified instead of the window visible in the captured pixels.

Copied files and folders are stored as path references only. The clipboard
history does not duplicate their contents, so moving or deleting a referenced
item can make an older history entry unavailable.
